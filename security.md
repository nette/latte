Supported Versions
==================

| Version | Supported                       |
|---------|---------------------------------|
| 3.1     | ✅ bug fixes and security fixes |
| < 3.1   | ❌ end of support               |

Only the latest release of a supported series receives fixes.


Reporting a Vulnerability
=========================

Please do not report security vulnerabilities through public GitHub issues. Report them privately via [GitHub Security Advisories](https://github.com/nette/latte/security/advisories/new).
